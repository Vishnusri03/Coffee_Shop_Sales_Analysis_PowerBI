# Coffee_Shop_Sales_Analysis_PowerBI
Coffee Shop Sales Analysis Dashboard using Power BI

## Project Overview
- This project focuses on analyzing coffee shop sales data using Microsoft Power BI.
- The Dashboard provides interactive visualizations to understand sales performance, customer purchasing patterns, and key business insights.

## Objectives
- Analyze overall coffee shop sales performance.
- Identify sales trends and patterns.
- Understand customer purchasing behaviour.
- Track important business KPIs.
- Create an interactive and user - friendly Power BI dashboard.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Dashboard
The Power BI dashboard presents key sales insights through interactive charts, graphs, and KPI visuals.
